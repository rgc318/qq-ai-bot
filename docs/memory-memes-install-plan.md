## 功能设置

- 仅开放测试群 347440128；群、人格之间隔离记忆。
- 捕获该群公开聊天作为记忆背景，每 10 轮整理，近期上下文窗口 50 条。
- 每轮自动召回最多 3 条；启用主动回忆和写入工具，关闭实验自主回忆及主动遗忘工具。
- 启用插件数据库备份，保留 7 天；低价值旧记忆归档保留。
- 表情包先用维护者提供的资源；普通分类模式，不额外调用视觉和向量模型。
- 每条完整回复最多 1 张，采用适量配图提示；关闭自动收集和云同步。
- 表情附加覆盖普通聊天与插件触发的 LLM 回复，以便兼容业镜。

完整非秘密配置草案：`config/memory-memes.plan.json`。安装脚本：`scripts/install-memory-memes.py`。
