# 18:51 双参考图改图失败

用户发送两张参考图，希望替换漫画中的兔子和恶魔狼。模型在 18:51:28 调用 `generate_image`，同时传入 `return_result=true` 和两条 `/AstrBot/data/temp/media_image_...png` 路径。万象画卷进入仅供插件内部使用的结果返回分支，该分支对显式本地 `refs` 要求位于插件数据目录，因而报“本地参考图不在允许目录内”。请求在本地校验阶段失败，尚未调用图像模型。

普通聊天工具的原始说明虽然写明 `return_result` 和 `refs` 仅供其他插件显式使用，但仍把这两个参数暴露给模型，模型选错了入口。此前生图前提示也跳过 `return_result=true`，所以这次不会先提示。

## 1.2.7 修改

- 在本地最后请求钩子中复制工具集和图片工具定义，移除聊天请求中的这两个内部参数；保持模型需要的 prompt/action、count、aspect_ratio、size 等参数。
- 工具执行前以高于等待提示的优先级清理模型可能输出的旧内部参数。普通生图/改图使用万象画卷正常入口，从当前消息和引用的图片中自动提取参考图，按原流程生成并自动下发。
- 不接受模型随意指定本地文件路径，不放宽内部 API 的目录限制。全局工具定义、其他插件直接使用的生成 API 和配额检查保持原样。
- 修复范围是同条消息或引用中实际提供的图片；不会自动从任意历史消息里寻找原漫画。需要严格保留旧漫画时，建议一并附上或引用原漫画及角色参考图。
