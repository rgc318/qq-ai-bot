# 历史图片仍在，但临时编号失效

2026-10-26 11:07，DeepSeek 已按新版协议提供任务声明、两张参考图及用途，前一轮的 missing_task 问题没有重现。但 reference_ids 使用此前聊天中的两个 ca_ 临时编号，运行层返回“参考图必须来自本轮已授权目录”。模型误把这句话解释为“历史图不能当底稿，需要重新上传”。

只读检查附件数据库：最近两条图片消息均为 ready，原始文件存在，未过期。没有请求图片模型；不是图片接口拒绝，也不是万象要求图片必须本轮上传。

根因在本地 ContextAware 接入层：上游内存图片索引每次导入生成随机 UUID，本地归档恢复会在重载/切换后重新导入，原始图片不变但编号改变；此前却允许这些临时编号作为完整工具调用留在较长历史里。本轮模型选中了旧编号。权限边界阻止了未知编号直接取图，但原错误反馈没有区分“编号失效”和“图片不可用”。
