## 本次修复

1. 判断超时后经主模型核对并成功回复，原始用户发言仍被保留为“对象未确认”，使下一句重复走 Qwen。现在仅在真实 LLM 回复发送后，按原消息 ID 和发送者确认该条关系；不猜测最新消息，不覆盖明确人类目标，旧人格迟到回复不更新新人格近期缓存。符合既有连续对话条件的后续短句可省掉接话判断。本次观察到的重复判断为 4.9 秒，不能保证每条都省下相同耗时。
2. AstrBot 原生事件 hook 会记录并吞掉校验异常，旧实现抛出“未明确是否沿用此前参考图”后仍生图。现在在请求内工具副本的实际 handler 边界返回未执行结果，错误参数不调用图片模型，也不生成开工对白；主模型可以修正参数或澄清。原注册工具和其他工具不变，拦截不覆盖此前图片任务的成功状态。新增脱敏 `image_guard_rejected / image_not_executed` 日志。

两项都是本地处理，没有新增正常路径模型调用、固定等待，未改动模型绑定及重试/超时设置。1.7.1 的系统收尾说明会增加少量输入 token；这些不同请求不能证明绝对零性能影响，目前没有证据表明它引入新的大段本地等待。参数校验未通过时，主模型修正参数可能产生额外轮次，这是纠正错误调用的代价。
